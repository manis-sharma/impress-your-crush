# 💖 Crush Proposal Website

An interactive and playful proposal website built with **HTML, CSS, and JavaScript**.  
This project is designed to impress your crush with smooth animations, background music, playful "Yes/No" buttons, and a beautiful photo gallery section.  

✨ Live Demo: [impress-your-crush](https://manishey.vercel.app/)

---

## 🚀 Features
- 🎶 Background music that auto-plays when the site starts  
- ⏳ Elegant loading screen with "Something special for you..."  
- 💌 Sweet text messages to impress her before the proposal  
- 😍 Proposal section with a **Yes button** and a **No button that runs away**  
- 🌸 Floating heart animations across the screen  
- 🖼️ Stylish 3D photo grid gallery after acceptance  
- 📱 Fully responsive design for mobile and desktop  

---

## 🛠️ Tech Stack
- **HTML5**
- **CSS3 (with animations)**
- **Vanilla JavaScript (no frameworks)**
